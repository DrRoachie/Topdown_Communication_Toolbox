06_Epoch_Analysis

Code needed to compare PSI values between epoch conditions. 

Epoch_Connectivity_Test.m: calculates PSI and coherence for all shared significant channel pairs that are collected from the phase shuffle fitler. 
PSI_Summary_Epoch.m and Summary_PValue_Spatial_Figure_Epoch.m: Calculates summary statistics,  generates heat map of average PSI per channel pair, and histograms of all PSI values.
